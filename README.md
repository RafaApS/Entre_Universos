# Entre Universos 📚✨

**Entre Universos** é uma plataforma web que funciona como um *streaming literário*: um espaço onde leitores podem descobrir suas próximas leituras e autores independentes podem publicar suas próprias histórias, ao estilo de plataformas como Wattpad, mas desenvolvido do zero como projeto acadêmico.

Este projeto é o **Trabalho de Conclusão de Curso (TCC)** do curso técnico da **ETEC Martinho Di Ciero**.

🔗 **Acesse o site:** 

<br>

## Sobre o projeto

A ideia por trás do Entre Universos nasceu da vontade de unir duas comunidades em um só lugar: leitores em busca de novas histórias e escritores que querem um espaço para publicar e divulgar seus trabalhos, sem as barreiras tradicionais do mercado editorial.

Na plataforma, é possível:

- Explorar histórias publicadas por diferentes autores
- Publicar suas próprias histórias e capítulos, para quem deseja ser autor
- Encontrar novas leituras de acordo com o interesse do leitor

<br>

## Como executar localmente

### Pré-requisitos

- Servidor local com suporte a PHP e MySQL (ex: [XAMPP](https://www.apachefriends.org/) ou [WampServer](https://www.wampserver.com/))

### Passos

1. Clone o repositório:
   ```bash
   git clone https://github.com/RafaApS/Entre_Universos.git
   ```
2. Mova a pasta do projeto para o diretório do seu servidor local (ex: `htdocs`, no caso do XAMPP).
3. Crie o banco de dados no MySQL e importe o(s) script(s) SQL disponíveis na pasta `bd/`.
4. Configure a conexão com o banco de dados nas classes correspondentes, dentro da pasta `class/`.
5. Inicie o Apache e o MySQL pelo painel do XAMPP/WampServer.
6. Acesse o projeto pelo navegador através do endereço local (ex: `http://localhost/Entre_Universos`).
